# closetheloop-dev skills

Agent skills maintained by closetheloop-dev.

## Install

Install the Omarchy plugin skill:

```sh
npx skills add closetheloop-dev/skills --skill omarchy-plugin
```

## Available skills

- [omarchy-plugin](skills/omarchy/omarchy-plugin/SKILL.md) — create, scaffold,
  validate, install, and debug Omarchy Quattro shell plugins built with Quickshell/QML.
